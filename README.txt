Depth Wiggle - native live wallpaper (depth clock + local touch jelly)

Build the APK with GitHub Actions:
1. Make a new GitHub repo. Upload the CONTENTS of this folder (settings.gradle, build.gradle,
   app/, .github/ ...) so settings.gradle sits at the repo root, not inside a subfolder.
2. Open the Actions tab, run "Build APK" (it also runs on every push).
3. Download the DepthWiggle-debug artifact, unzip it, install the .apk.
4. Open the app, pick a photo, paint over the subject, tap Set wallpaper.
